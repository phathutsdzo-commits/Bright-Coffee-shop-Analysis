# Bright-Coffee-shop-Analysis
Project Overview 

This project was completed as part of the BrightLearn Data Analytics Case Study (2026). The objective of the project is to analyze historical coffee shop sales data and provide actionable business insights to help the CEO improve revenue, product performance, and sales strategies

The analysis focuses on:

- Identifying the products that generate the most revenue.
- Determining peak sales periods during the day.
- Understanding sales trends across products and time intervals.
- Providing data-driven recommendations to improve business performance.

Business Problem

Bright Coffee Shop recently appointed a new CEO whose objective is to grow company revenue and improve product performance. As a Junior Data Analyst, I was tasked with transforming raw transactional data into meaningful insights that support strategic decision-making.

The project aims to:

- Calculate total revenue.
- Identify best-selling and underperforming products.
- Analyze sales by product category.
- Determine peak sales time intervals.
- Analyze store performance.
- Provide recommendations for improving sales performance.
- Present findings through dashboards and presentations

Tools used
Databricks for Data cleaning, SQL analysis dashboard creation
Microsoft Excel for Pivot tables and dashboard creation 
PowerPoint for Presentation of business insights 
Miro for Data architecture and planning
Power BI and Data studio for dashboard creation
Canva to create Gantt chart
